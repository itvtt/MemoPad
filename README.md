# MemoPad

바탕화면 붙임 메모 + 메모 주고받기 · 회람 · 대화. 정음 메모패드의 기능을 그대로 옮겼고, **정음 메모패드와 같은 형식으로 주고받습니다** (정음 메모패드를 쓰는 사람과 메모 · 첨부 · 회람 · 상태 확인 · 부재중 · 대화가 됨).

- 기능 대응표: `docs/features.md` (정음 메모패드의 메뉴 · 대화상자 · 설정을 하나씩 옮긴 표)
- 통신 형식: `docs/protocol.md`

## 쓰기

| 어디서 | 하는 일 |
|---|---|
| 트레이 아이콘 클릭 | 새 메모 (Ctrl+클릭 = 모두 보이기, Alt+클릭 = 메모 관리기) |
| 트레이 오른쪽 클릭 | 새 메모 · 새 그림 · 대화창 · 메모 관리기 · 모두 보이기/숨기기 · 바탕화면 메모 정렬 · 모두 버리기 · 주소록 · 사용자 상태 확인 · 부재중 · 설정 · 종료 |
| 메모 머리 | 끌어서 옮기기, 두 번 클릭 = 접기/펼치기, ≡ 또는 오른쪽 클릭 = 메모 메뉴, 📌 항상 위, ─ 접기, ✕ 버리기(휴지통) |
| 메모 본문 오른쪽 클릭 | 편집 메뉴 (글꼴 · 글자 색 · 형광펜 · 글머리표 · 정렬 · 날짜/시간 · 표 · 그림 · 한/영 오타 변환) |

| 단축키 (메모 안) | |
|---|---|
| `Ctrl+N` | 새 메모 |
| `Ctrl+S` · `Ctrl+Y` · `Ctrl+F` | 보내기 · 답장(받은 메모) · 전달 |
| `Ctrl+D` · `Ctrl+T` | 날짜 · 시간 넣기 (형식은 설정) |
| `Ctrl+M` | 그림 넣기 |
| `F4` | 한/영 오타 변환 (고른 글자, 없으면 커서 앞 낱말) |
| `Ctrl+Shift+V` | 텍스트만 붙여넣기 |
| `Ctrl+P` | 인쇄 |
| `Alt+F4` | 버리기 (휴지통) |
| `Ctrl+B/I/U` · `Ctrl+L/E/R` · `Ctrl+Shift+L` · `Ctrl+Num+/-` | 굵게 · 기울임 · 밑줄 · 정렬 · 글머리표 · 들여쓰기 |

- 메모 메뉴: 보내기 · 답장 · 전달 · 회람(돌리기 · 전달 · 상태 조회) · 보낸 사람(정보 · 주소록에 추가 · 대화) · 알람 · 바탕 색 · 옵션(항상 위 · 항상 아래 · 잠그기 · 읽기 전용 · 보안 메모 · 상태줄 · 투명도) · 파일(첨부 · 불러오기 · 저장 · 그림으로 저장 · 인쇄) · 숨기기 · 버리기.
- 파일을 메모에 끌어 놓으면 첨부 (그림 한 장을 본문에 놓으면 그림 넣기).
- 그림 메모: 펜 6색 · 굵기 3단 · 지우개 · 되돌리기 · 다시 · 전부 지우기 · 확대/축소. 보낼 때는 그림 한 장짜리 RTF 로 (정음 메모패드에서도 보임).
- 메모 관리기: 폴더 · 휴지통(되살리기 · 비우기) · 찾기 · 끌어서 폴더로 옮기기 · 정음 메모 가져오기(정음 메모패드의 `.HMD`).
- 회람: 받을 사람 순서대로 돌고, 받은 사람은 맨 위 "[이름의 의견]" 아래에 의견을 쓰고 [회람 전달]. 마지막 사람이 전달하면 시작한 사람에게 "[회람 결과입니다.]" 메모가 옵니다. 시작한 사람은 [회람 상태 조회]로 받음 · 전달을 봅니다. 정음 메모패드는 회람 대상의 **ID** 로 자기 자리를 찾으니, 주소록에 ID 를 넣어 두세요.

## 네트워크

- 포트 TCP 9710(메모) · 9712(대화) · 9726~(첨부)를 씁니다. 처음 켤 때 Windows 방화벽이 물으면 허용하세요.
- 같은 PC 에서 정음 메모패드와 함께 켤 수 없습니다 (같은 포트). 정음 메모패드를 끄고 쓰세요 (설정 → 내 정보에 "받을 수 없음"이 보이면 다른 프로그램이 포트를 쓰는 것).
- 내 정보(이름 · ID · E-Mail · 대화명 · IP)는 설정 → 내 정보. 네트워크 카드가 여럿이면 IP 를 골라 두세요.
- 주소록 폴더를 공유 폴더로 지정하면 여러 사람이 한 주소록(`addressbook.json`)을 씁니다.

## 저장 위치

- `%LOCALAPPDATA%\MemoPad\` (설치 폴더 밖이라 업데이트해도 남음)
  - `memos\<id>.json` 메모 하나에 파일 하나, 첨부는 `memos\<id>\files\`
  - `settings.json` 설정 (보안 암호는 해시만), `folders.json` 메모 관리기 폴더, `addressbook.json` 주소록 (주소록 폴더를 바꾸지 않았을 때)
  - `memopad.log` 오류 기록 (어떤 오류에도 앱은 꺼지지 않고 여기에 남김)
- 시험할 때는 환경 변수 `MEMOPAD_DATA_DIR` 로 다른 폴더를 씁니다. `MEMOPAD_BIND` (받을 주소, 예: `127.0.0.1`), `MEMOPAD_MEMO_PORT` · `MEMOPAD_CHAT_PORT` (받을 포트), `MEMOPAD_REMOTE_PORT` · `MEMOPAD_REMOTE_CHAT_PORT` (상대 포트)로 한 PC 에서 여럿을 띄울 수 있습니다.
- 설치된 사본은 처음 실행할 때 "Windows 시작할 때 실행"을 켭니다 (`--tray`). 설정 → 일반에서 끕니다.

## 빌드 · 확인

```powershell
dotnet build MemoPad\MemoPad.csproj -c Release
dotnet run --project MemoPad.Checks -c Release
```

`MemoPad.Checks` 는 한/영 변환, 메모 머리(정음 배치 포함), RTF, 주소록, 저장소, 정음 메모 파일, 대화 메시지, 그리고 이 PC 안에서 127.0.0.5~7 주소로 메모 · 큰 첨부 · 상태 · 부재중 · 회람(3명) · 대화(3명)를 주고받아 확인합니다. 인자로 더 할 수 있습니다:

| 인자 | 하는 일 |
|---|---|
| `--snapshot <폴더>` | 메모 · 그림 메모 · 메모 관리기 · 설정 · 주소록을 PNG 로 |
| `--jungum <IP> <ID>` | 실제 정음 메모패드에 상태 확인 · 메모 + 첨부 · 회람을 보내고, 그쪽에서 [회람 전달]하면 결과를 확인 |
| `--jungum-wait <초>` | 받는 쪽으로 기다림: 받은 회람은 의견을 달아 전달, 받은 메모는 답장, 들어온 대화를 출력 |
| `--jungum-chat <IP>` | 그쪽 대화방에 들어가 말하고 나옴 |

실제 시험의 이 PC 주소는 `MEMOPAD_LIVE_IP` (기본 `127.0.0.9`: 같은 PC 에서 정음 메모패드가 9710 을 쓰고 있어도 됨), ID 는 `MEMOPAD_LIVE_ID`.

## 릴리스

`main` 에 push 하면 self-hosted 러너가 다음 버전을 골라 `MemoPad-win-x64.zip` 을 릴리스합니다 (i-luncher AppKit, `.github\workflows\release.yml`). 설정 키는 `.env.sample`, 값은 프로필 폴더(`APPS_ENV_DIR`)의 `MemoPad.env` 에 둡니다.
