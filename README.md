# MemoPad

바탕화면 붙임 메모. 정음 메모패드의 메모 기능(서식 · 표 · 그림 메모 · 알람 · 보안 · 메모 관리기)을 옮겼습니다.
**포트를 쓰는 기능(메모 주고받기 · 회람 · 사용자 상태 확인 · 부재중 · 대화 · 주소록)은 꺼 두었습니다.** 포트를 하나도 열지 않고 메뉴 · 트레이 · 단축키 · 설정에도 보이지 않습니다 (아래 [네트워크 기능 (꺼 둠)]).

- 기능 대응표: `docs/features.md` (정음 메모패드의 메뉴 · 대화상자 · 설정을 하나씩 옮긴 표)

## 쓰기

| 어디서 | 하는 일 |
|---|---|
| 트레이 아이콘 클릭 | 새 메모 (Ctrl+클릭 = 모두 보이기, Alt+클릭 = 메모 관리기) |
| 트레이 오른쪽 클릭 | 새 메모 · 새 그림 · 메모 관리기 · 모두 보이기/숨기기 · 바탕화면 메모 정렬 · 모두 버리기 · 설정 · 종료 |
| 메모 머리 | 끌어서 옮기기, 두 번 클릭 = 접기/펼치기, ≡ 또는 오른쪽 클릭 = 메모 메뉴, 📌 항상 위, ─ 접기, ✕ 버리기(휴지통) |
| 메모 본문 오른쪽 클릭 | 편집 메뉴 (글꼴 · 글자 색 · 형광펜 · 글머리표 · 정렬 · 날짜/시간 · 표 · 그림 · 한/영 오타 변환) |

| 단축키 (메모 안) | |
|---|---|
| `Ctrl+N` | 새 메모 |
| `Ctrl+D` · `Ctrl+T` | 날짜 · 시간 넣기 (형식은 설정) |
| `Ctrl+M` | 그림 넣기 |
| `F4` | 한/영 오타 변환 (고른 글자, 없으면 커서 앞 낱말) |
| `Ctrl+Shift+V` | 텍스트만 붙여넣기 |
| `Ctrl+P` | 인쇄 |
| `Alt+F4` | 버리기 (휴지통) |
| `Ctrl+B/I/U` · `Ctrl+L/E/R` · `Ctrl+Shift+L` · `Ctrl+Num+/-` | 굵게 · 기울임 · 밑줄 · 정렬 · 글머리표 · 들여쓰기 |
| `Ctrl+Z` · `Ctrl+Y` (그림 메모) | 되돌리기 · 다시 |

- 메모 메뉴: 새 메모 · 새 그림 · 메모 관리기 · 알람 · 바탕 색 · 옵션(항상 위 · 항상 아래 · 잠그기 · 읽기 전용 · 보안 메모 · 상태줄 · 투명도) · 파일(첨부 · 불러오기 · 저장 · 그림으로 저장 · 인쇄) · 숨기기 · 버리기.
- 파일을 메모에 끌어 놓으면 첨부 (그림 한 장을 본문에 놓으면 그림 넣기).
- 그림 메모: 펜 6색 · 굵기 3단 · 지우개 · 되돌리기 · 다시 · 전부 지우기 · 확대/축소.
- 메모 관리기: 폴더 · 휴지통(되살리기 · 비우기) · 찾기 · 끌어서 폴더로 옮기기 · 정음 메모 가져오기(정음 메모패드의 `.HMD` 파일을 읽음, 포트 안 씀).

## 네트워크 기능 (꺼 둠)

- 코드 스위치 `Core\Features.cs` 의 `Network` 가 꺼져 있습니다 (기본). 설정 파일의 값과 상관없이 포트를 열지 않고, 보내기 · 답장 · 전달 · 회람 · 보낸 사람 · 사용자 상태 확인 · 부재중 · 대화창 · 주소록과 설정의 내 정보 · 받기 · 보내기가 보이지 않습니다.
- 코드는 남아 있습니다. `MemoPad.Checks` 는 스위치를 켜고 시험해 코드가 깨지지 않게 합니다. 다시 쓰려면 스위치를 켜고 릴리스합니다.
- 켜면 이렇게 동작합니다 (정음 메모패드와 같은 형식, `docs/protocol.md`):
  - MemoPad 포트 TCP 9810(메모) · 9812(대화) · 9826~(첨부)로 받아, 정음 메모패드(9710 · 9712 · 9726~)와 한 PC 에 함께 켜 둘 수 있습니다.
  - 보낼 때는 상대가 MemoPad 면 MemoPad 로, 정음 메모패드만 있으면 정음 메모패드로 갑니다. 이 PC 에 정음 메모패드가 없으면 정음 포트로도 받습니다.
  - 회람: 받을 사람 순서대로 돌고 마지막 사람이 전달하면 시작한 사람에게 "[회람 결과입니다.]" 메모가 옵니다. 정음 메모패드는 회람 대상의 **ID** 로 자기 자리를 찾으니 주소록에 ID 를 넣어 둡니다.
  - 내 정보(이름 · ID · E-Mail · 대화명 · IP)는 설정 → 내 정보, 주소록 폴더를 공유 폴더로 지정하면 여러 사람이 한 주소록을 씁니다.

## 저장 위치

- `%LOCALAPPDATA%\MemoPad\` (설치 폴더 밖이라 업데이트해도 남음)
  - `memos\<id>.json` 메모 하나에 파일 하나, 첨부는 `memos\<id>\files\`
  - `settings.json` 설정 (보안 암호는 해시만), `folders.json` 메모 관리기 폴더, `addressbook.json` 주소록 (주소록 폴더를 바꾸지 않았을 때)
  - `memopad.log` 오류 기록 (어떤 오류에도 앱은 꺼지지 않고 여기에 남김)
- 시험할 때는 환경 변수 `MEMOPAD_DATA_DIR` 로 다른 폴더를 씁니다. `MEMOPAD_BIND` (받을 주소, 예: `127.0.0.2`)를 서로 다르게 주면 한 PC 에서 여럿을 띄울 수 있습니다. `MEMOPAD_JUNGUM_PORTS` = `1` · `0` 은 정음 포트로도 받을지를 정합니다 (없으면 이 PC 에 정음 메모패드가 없을 때만). `MEMOPAD_MEMO_PORT` · `MEMOPAD_CHAT_PORT` 는 MemoPad 포트를 바꿉니다 (모두 같은 값을 써야 서로 주고받음).
- 설치된 사본은 처음 실행할 때 "Windows 시작할 때 실행"을 켭니다 (`--tray`). 설정 → 일반에서 끕니다.

## 빌드 · 확인

```powershell
dotnet build MemoPad\MemoPad.csproj -c Release
dotnet run --project MemoPad.Checks -c Release
```

`MemoPad.Checks` 는 네트워크 기능이 꺼져 있으면 포트를 하나도 열지 않는지와, 한/영 변환, 메모 머리(정음 배치 포함), RTF, 주소록, 저장소, 정음 메모 파일, 대화 메시지, 그리고 이 PC 안에서 127.0.0.5~10 주소로 메모 · 큰 첨부 · 상태 · 부재중 · 회람(3명) · 대화(3명)와 포트(정음 메모패드와 한 PC 에 함께 켜진 곳 · 정음 메모패드만 있는 곳 · 정음 대화방)를 주고받아 확인합니다. (네트워크 시험은 스위치를 켜고 함.) 인자로 더 할 수 있습니다:

| 인자 | 하는 일 |
|---|---|
| `--snapshot <폴더>` | 메모 · 그림 메모 · 메모 관리기 · 설정 · 주소록을 PNG 로 |
| `--jungum <IP> <ID>` | 실제 정음 메모패드에 상태 확인 · 메모 + 첨부 · 회람을 보내고, 그쪽에서 [회람 전달]하면 결과를 확인 |
| `--jungum-wait <초>` | 받는 쪽으로 기다림: 받은 회람은 의견을 달아 전달, 받은 메모는 답장, 들어온 대화를 출력 |
| `--jungum-chat <IP>` | 그쪽 대화방에 들어가 말하고 나옴 |
| `--status <IP>` | 상태 확인만 (MemoPad, 없으면 정음 메모패드가 답함. 그쪽 화면에는 아무것도 뜨지 않음) |

실제 시험의 이 PC 주소는 `MEMOPAD_LIVE_IP` (기본 `127.0.0.9`: 정음 포트로도 받으므로, 같은 PC 의 정음 메모패드는 다른 주소에서 9710 을 써야 함), ID 는 `MEMOPAD_LIVE_ID`.

## 릴리스

`main` 에 push 하면 self-hosted 러너가 다음 버전을 골라 `MemoPad-win-x64.zip` 을 릴리스합니다 (i-luncher AppKit, `.github\workflows\release.yml`). 설정 키는 `.env.sample`, 값은 프로필 폴더(`APPS_ENV_DIR`)의 `MemoPad.env` 에 둡니다.
