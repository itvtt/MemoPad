# 정음 메모패드 기능 대응표

정음 메모패드 9.5(JUMemoPad)의 도움말 · 메뉴 · 대화상자 · 설정 항목을 하나씩 옮긴 표입니다. MemoPad 를 고칠 때 이 표를 함께 고칩니다.
**네트워크 기능(포트를 쓰는 것)은 꺼 두었습니다**: 아래에서 "꺼 둠"인 줄은 앱에 보이지 않고 포트도 열지 않습니다. 코드는 남아 있어 `Core\Features.cs` 의 `Network` 로 다시 켤 수 있습니다.
켜면 정음 메모패드와 **같은 형식**으로 주고받습니다 (`docs/protocol.md`, 실제 정음 메모패드와 양쪽 방향으로 확인함). 자기 포트(9810 · 9812)를 써서 같은 PC 의 정음 메모패드와 부딪히지 않습니다.

## 트레이 아이콘

| 정음 메모패드 | MemoPad |
|---|---|
| 아이콘 클릭 = 새 메모 | 같음 |
| Ctrl+클릭 = 모두 보이기, Alt+클릭(길게 누르기) = 메모 관리기 | 같음 |
| 메뉴: 새 메모 · 새 그림 · 대화창 열기 · 메모 관리기 · 모두 보이기 · 모두 숨기기 · 모두 버리기 · 주소록 수정 · 사용자 상태 확인 · 부재중 상태 · 설정 · 종료 | 같음 (+ 바탕화면 메모 정렬). 대화창 · 주소록 · 사용자 상태 확인 · 부재중은 꺼 둠 |
| 프린터 설정 · 정보 · 홈페이지 · 업데이트 · 추천하기 · 도움말 | 인쇄 창에서 프린터를 고름, 업데이트는 i-luncher 자체 업데이트 |
| 서버 접속 · 서버 주소록 · 조직도 (전용 서버) | 없음: 주소록 폴더를 공유 폴더로 지정하면 여러 사람이 한 주소록을 씀 |

## 메모 창

| 정음 메모패드 | MemoPad |
|---|---|
| 여러 개, 끌어서 이동, 테두리로 크기 조절 | 같음 |
| 아이콘 표시(작게 접기) · 화면 복귀: 메모 색 22×22 사각형 (클립 그림), 접기 단추 자리. 두 번 클릭하면 그 자리에서 펼침 | 같음: 메모 색 24×24 사각형 (글줄 · 접힌 귀, 그림 메모는 선, 보안 메모는 자물쇠), 메모의 오른쪽 위 자리. 두 번 클릭 · Enter · 메뉴 [펼치기]로 펼치면 사각형 자리를 오른쪽 위로 해서 열림. 끌어서 옮기기, 마우스를 올리면 첫 줄 |
| 버리기 (Alt+F4) | 같음, 휴지통으로 (메모 관리기에서 복구) |
| 바탕 색 (팔레트 · 사용자 정의 · 배경 이미지) | 팔레트 10색 · 직접 고르기 |
| (메모마다 글꼴은 없음: 설정의 기본 글꼴만) | 메모 메뉴 → 글꼴 · 글자 크기: 메모마다 본문 전체 (맨 위 "기본" = 설정의 글꼴 · 크기, 이 PC 에 있는 글꼴만 그 글꼴로 보임, 다른 글꼴…), Ctrl+휠로 한 단계 |
| 항상 위 · 항상 아래 · 숨기기 | 같음 |
| 잠그기 | 위치 · 크기 고정 |
| 읽기 전용 | 같음 |
| 보안 상태 (암호) | 내용을 가리고 암호를 넣어야 보임 (설정 → 보안 암호) |
| 투명 메모 · 투명도 변경 (10~245) | 메모마다 투명도 |
| 상태줄 보이기 | 만든 · 받은 · 고친 시각, 첨부 · 알람 표시 |
| 알람 설정 (날짜 · 시간 · 미리 알림 · 소리 · 설명) | 같음: 정시~2시간 전, 소리 파일, 설명. 시간이 되면 알림 창 + 메모를 앞으로 |
| 파일: 다른 파일 불러오기(RTF · TXT) · 파일로 저장하기 · 이미지 저장 | 같음 (+ PNG 로 저장) |
| 인쇄 (생성 · 받은 · 최종편집 · 인쇄 시간 머리글) | 같음 |
| 새 그림 (펜 굵기 · 펜 색 · 그리기 취소 · 다시 그리기 · 전부 지우기 · 보기 배율) | 그림 메모: 펜 6색 · 굵기 3단 · 지우개 · 되돌리기 · 다시 · 전부 지우기 · 확대 · 축소 |
| 파일 첨부하기 · 첨부 저장 · 실행 | 같음 (여러 개 · 폴더는 zip, 첨부 띠: 두 번 클릭 = 열기 · 실행, 오른쪽 클릭 = 다른 이름으로 저장 · 빼기) |
| 정음 스케쥴러로 보내기 · 불러오기, 팜 파일럿 핫싱크, 아웃룩 메모 동기화 | 없음 (해당 프로그램 없음) |

## 편집 (메모 안에서 오른쪽 클릭)

| 정음 메모패드 | MemoPad |
|---|---|
| 글꼴 · 글머리표 · 들여쓰기 · 정렬 (Ctrl+L/E/R) | 같음 (+ 굵게 · 기울임 · 밑줄 · 글자 색 · 번호) |
| 되돌리기 · 잘라내기 · 복사 · 붙여넣기 · 선택하여 붙여넣기 · 전체 선택 | 같음 (선택하여 붙여넣기 = 텍스트만 붙여넣기) |
| 날짜 입력 Ctrl+D · 시간 입력 Ctrl+T (형식은 설정) | 같음 |
| 표 삽입 · 그림 삽입 | 같음 |
| 개체 삽입 · 편집 (OLE) | 없음 (그림 · 표로 대신) |
| 한/영 오타 변환 F4 | 같음: 선택한 글자 (없으면 커서 앞 낱말)를 한글 ↔ 영문 자판으로 |

## 주고받기 (꺼 둠)

| 정음 메모패드 | MemoPad |
|---|---|
| 보내기 Ctrl+S (받을 사람 지정: 이름 입력 · 주소록 · 순서) | 같음 |
| 답장 보내기 Ctrl+Y (받은 메모를 고쳐서 보낸 사람에게) | 같음, 고친 내용이 없으면 물어봄 |
| 전달 Ctrl+F | 같음 |
| 회람 돌리기 · 회람 전달 (의견 붙이기) · 회람 결과 · 회람 상태 조회 · 없는 사람 다시 보내기 | 같음 |
| 받은 메모에 '>' 추가 · 받은 메모를 맨 위로 · 보낸 후 버림 · 미수신인 매번 확인 | 설정에 같음 |
| 받은 메모를 다른 주소로 전달 | 설정 → 받은 메모 전달 주소 |
| 보낸 사람 정보 · 주소록에 추가 · 보낸 사람과 채팅 | 같음 |
| 부재중 상태 + 안내 문구 | 같음 (보낸 사람에게 문구가 감) |
| 사용자 상태 확인 (있음 · 부재중 · 꺼져 있음, 반응 시간, 파일로 저장) | 같음 |
| 주소록 (그룹 · 이름 · ID · IP · E-Mail, 끌어서 그룹 이동, 다른 주소록 불러오기, vCard 저장) | 같음 (불러오기 · 내보내기는 CSV) |
| 나의 네트워크 정보 (이름 · ID · E-Mail · 대화명 · IP) | 같음 |
| 네트워크 기능 사용 끄기 | 같음 |
| 수신 메모 가상 IP → 실제 IP | 없음 (받을 때 연결한 주소를 씀) |

## 대화창 (SimpleChat) (꺼 둠)

| 정음 메모패드 | MemoPad |
|---|---|
| 접속 변경 (주소록 사용자 · 특정 IP) | 같음 |
| 대화 · 참여자 목록 · 입실/퇴실 알림 | 같음 |
| 대화방 잠그기 | 같음 (MemoPad 가 방장일 때) |
| 초대 · 귓속말 · 얼굴 바꾸기 | 없음 (상대가 [접속 변경]으로 들어옴) |
| 갈무리 (대화 내용 파일로) | 같음 |
| 대화명 · 단축키 정의(F1~F12 문구) | 같음 (대화명은 설정 → 내 정보) |

## 설정

| 정음 메모패드 | MemoPad |
|---|---|
| 환경: 소리 · 애니메이션 · 시작 프로그램에 추가 · 트레이로 관리기 자동 띄움 · 항상 타이틀 보이기 · 비활성 메모 테두리 숨김 · 날짜/시간 형식 | 같음 (애니메이션 제외) |
| 메모 기본값: 글꼴 · 바탕색 · 넓이 · 높이 · 스크롤바 · 위치(보통 · 항상 위) · 새 메모 투명 · 최소화 메모 투명 | 같음. 처음 설치하면 새 메모 · 받은 메모는 항상 위 (설정에서 끔) |
| 보안: 암호 사용 · 받은 메모는 항상 보안 상태 | 같음 (받은 메모 쪽은 꺼 둠) |
| 휴지통: 삭제 메모는 휴지통으로 | 같음 (기본 켜짐) |
| 주소록 파일 폴더 (공유 폴더) | 같음 |
| (데이터 폴더는 설치 폴더 안 Desktop) | 데이터 폴더: 처음 실행할 때 고르고, 설정에서 바꾸면 옮긴 뒤 다시 시작 |
| — | 단축키: 모두 보이기 · 모두 숨기기 (전역, 처음에는 없음) |
| 언어 선택 | 한국어만 |
| Shareware 등록 | 없음 |
